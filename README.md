# Rina's Portfolio

My personal portfolio website showcasing my experience in software development, AI engineering, and full-stack applications, along with my projects, technical skills, and professional background.

🌐 **Live Website:** [rinaosman.com](https://www.rinaosman.com/)

## 👩‍💻 About

Built with **Next.js, React, TypeScript, and Tailwind CSS**, this portfolio highlights my work across full-stack development, AI agents, backend engineering, and cloud technologies.

The website features a responsive design, interactive project showcases, an experience and education timeline, and a contact form.

## 🧱 Tech Stack

- **Framework:** Next.js (App Router), React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

To run the website locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
